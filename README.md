# LSignal

## О проекте

`LSignal` — атмосферный игровой прототип на `pygame`, в центре которого находятся аномалии, игровые события и состояние мира. По структуре проект выглядит как экспериментальная игра с мрачной подачей, где логика, визуализация и ввод уже разнесены по отдельным модулям.

## Что есть в проекте

- центральное состояние игры в `game_state.py`;
- обработка событий клавиатуры и мыши;
- система аномалий;
- отдельный графический слой для отрисовки сцены;
- папка `old/` со старой версией, которую можно использовать как исторический срез развития идеи.

## Стек и структура

- Python
- `pygame`
- основные файлы: `main.py`, `game_state.py`, `events.py`, `mouse.py`, `anomaly.py`, `graphics.py`

## Запуск

```bash
python main.py
```
